# Distichlis ChrB methods

Static GitHub Pages site documenting the computational workflow used for k-mer-based ChrB detection and dosage estimation in *Distichlis*.

## Local preview

Open `index.html` directly in a browser. No build step is required.

## GitHub Pages deployment

1. Create an empty GitHub repository.
2. Upload this directory's contents to the repository root.
3. In GitHub, open **Settings > Pages** and deploy from the `main` branch, root directory.

The repository includes publication-aligned ChrB-marker, SDR-marker, WGS-screening, reference-marker, and downsampling scripts. See [METHODS_SCRIPT_AUDIT.md](METHODS_SCRIPT_AUDIT.md) for a transparent script-to-manuscript mapping. The final GMMAT GWAS workflow remains pending until its exact preparation, model-fitting, annotation, and enrichment scripts are added.
