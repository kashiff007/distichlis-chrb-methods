Reproducible analysis companion

k-mer-based detection and quantification of B chromosomes

A practical workflow for discovering conserved ChrB-specific 21-mers from whole-genome sequencing, screening new libraries, estimating ChrB dosage, and evaluating performance at reduced sequencing input.

Scope. This repository documents the computational methods used in Nawaz et al., K-mer-based population-scale detection and quantification of B chromosomes from ultra-low-coverage whole-genome sequencing. It does not contain WGS reads, genome assemblies, or sample metadata with restricted access.

Core workflow

From cytology-anchored k-mers to population-scale ChrB calls

  1. 01Define training panels

    Use cytologically confirmed ChrB-positive and ChrB-negative genets.

  2. 02Count canonical 21-mers

    Generate per-sample k-mer files from paired-end WGS reads with Jellyfish.

  3. 03Discover conserved markers

    Intersect k-mers shared across ChrB-positive genets.

  4. 04Remove standard-genome signal

    Exclude every candidate present in any ChrB-negative genet.

  5. 05Screen WGS libraries

    Count retained marker k-mers, normalize by total sequenced bases, and infer dosage.

Marker discovery

WGS-derived ChrB marker panel

Twenty-six cytologically confirmed ChrB-positive D. spicata and D. stricta genets were used to identify canonical 21-mers shared across the positive training panel. The resulting common set was screened against 75 cytologically confirmed ChrB-negative genets. Any k-mer observed in a negative library was removed, yielding the WGS-derived ChrB marker set.

The finalized panel contained 201,278 putative ChrB-specific 21-mers. The workflow is intentionally assembly-independent during marker discovery.

Library screening and dosage

Normalize marker abundance before estimating copy number

For each WGS library, canonical 21-mers are counted with Jellyfish and the number of distinct detected WGS-marker-set k-mers is recorded. To account for sequencing effort, abundance is expressed per million sequenced bases:

normalized ChrB abundance = (ChrB-specific k-mer hits × 1,000,000)
                            / (paired-end read pairs × 300 bp)

For the WGS-marker set, the unrounded predicted ChrB copy number is calculated as normalized abundance divided by 12. This scaling factor was calibrated against independent cytological chromosome counts. ChrB status is then derived from the calibrated abundance/copy-number signal according to the study criteria.

The included Jellyfish scanner accepts a three-column sample sheet (sample_id, R1, R2), is suitable for a Slurm array, and writes an independent result file per library to avoid concurrent writes to a shared table.

Independent validation

Reference-derived marker panel

A second panel was generated from the k-mers shared among three independently assembled ChrB sequences. K-mers present in the A chromosomes, chloroplast, or mitochondrial sequences of the three reference genomes were excluded. The reference-derived panel offered an orthogonal sequence-based validation of the WGS-derived markers.

Sex-marker workflow

Female-enriched SDR 21-mers

The same discovery logic was applied to observed-sex training genets: identify k-mers shared or enriched among females and remove k-mers observed among males. These markers were then used to infer sex from WGS, with performance evaluated against independently observed sex.

Sensitivity analysis

In silico downsampling

High-coverage paired-end WGS libraries from 40 cytologically validated genets, including 20 ChrB-positive and 20 ChrB-negative genets, were downsampled independently across a range of input fractions. Each subset was re-screened using the WGS-marker set and the predicted copy number was compared with cytology.

In this dataset, detection and dosage remained concordant with cytology to approximately 0.5× coverage; uncertainty increased at lower coverage.

Association mapping

GWAS of ChrB presence

The manuscript reports an eastern D. spicata GWAS of ChrB presence/absence using 292 genets, including 94 ChrB-positive and 198 ChrB-negative individuals. The analysis used a binomial logistic mixed model in GMMAT to account for population structure and relatedness.

The manuscript's final binary association model was fit in GMMAT; its phenotype preparation, logistic mixed-model, annotation, and enrichment scripts will be added once deposited. A separate GLM/GEMMA sensitivity-analysis script is retained in scripts/archive and is not presented as the final manuscript GWAS workflow.

Software

Minimum computational requirements

  • Jellyfish for canonical 21-mer counting.
  • GNU coreutils for sorting and set intersections.
  • Seqtk and GNU Parallel for read downsampling.
  • A Slurm-compatible scheduler for the example high-memory and multi-core workloads.

Example commands assume 2 × 150-bp paired-end reads and 30 threads. Update input paths, file names, memory allocation, and the marker-panel filename for your environment.
